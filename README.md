# EduPredict – Sistema Inteligente de Análisis y Predicción del Rendimiento Académico

**EduPredict** es una aplicación web desarrollada en Python mediante el framework Streamlit, orientada al análisis de datos académicos y la predicción del rendimiento estudiantil utilizando técnicas de minería de datos y aprendizaje automático (*Machine Learning*).

Su principal objetivo es facilitar la identificación de patrones relacionados con el desempeño académico, permitiendo analizar variables como las horas de estudio, el porcentaje de asistencia, las tareas entregadas y las calificaciones obtenidas.

La plataforma permite importar archivos CSV y Excel, validar la calidad de los datos, identificar registros duplicados o incompletos y visualizar información mediante dashboards interactivos, indicadores estadísticos y gráficos.

Además, EduPredict incorpora dos algoritmos de clasificación: **Árbol de Decisión y Regresión Logística**, que permiten estimar si un estudiante aprobará o reprobará una asignatura a partir de sus características académicas. Los modelos pueden evaluarse mediante métricas como exactitud, precisión, sensibilidad, F1 y matrices de confusión.

El sistema también ofrece herramientas de análisis por asignatura, identificación de estudiantes que requieren seguimiento, generación de recomendaciones académicas y exportación de reportes en formatos CSV y Excel.

**EduPredict busca transformar los datos académicos en información útil para apoyar la toma de decisiones educativas**, contribuyendo a la identificación temprana de posibles dificultades académicas y al fortalecimiento de las estrategias de acompañamiento estudiantil.

### Tecnologías utilizadas
- **Lenguaje:** Python.
- **Framework web:** Streamlit.
- **Análisis de datos:** Pandas y NumPy.
- **Visualización:** Plotly.
- **Machine Learning:** Scikit-learn.
- **Algoritmos:** Árbol de Decisión y Regresión Logística.
- **Procesamiento de archivos:** CSV y Excel.
